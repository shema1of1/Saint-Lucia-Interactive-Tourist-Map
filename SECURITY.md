# Security Policy

## Reporting a vulnerability

Please do **not** publish security vulnerabilities in a public GitHub issue.

If you discover a vulnerability affecting 360MAP / Saint Lucia Interactive Tourist Map, contact the repository owner privately through their GitHub profile and include:

- A clear description of the issue
- The affected page, file, or feature
- Steps to reproduce the issue
- The potential impact
- Any suggested remediation, if known

Please avoid accessing, modifying, or retaining data that does not belong to you while investigating a suspected vulnerability.

## Supported version

The current production version published from the `main` branch is the supported version.

## Secrets and credentials

API keys, passwords, access tokens, private keys, registrar credentials, and other secrets must never be committed to this repository or embedded in client-side JavaScript.

## Responsible disclosure

We appreciate good-faith reports that give the project owner a reasonable opportunity to investigate and remediate a vulnerability before public disclosure.
